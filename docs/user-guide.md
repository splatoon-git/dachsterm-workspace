## 화면 구성과 단축키

| 위치             | 내용                                                                                                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **＋ 새 연결**   | 새 연결과 로컬 터미널(PowerShell, 명령 프롬프트, WSL 등) 목록                                                                                                                                         |
| **보기**         | 파일, 터미널 미리보기, 모든 탭 배치, 전체화면, 키보드 단축키                                                                                                                                          |
| **도구**         | 스니펫, 기본 명령·로그 필터, PodTree 열기, 터널                                                                                                                                                       |

## SSH 연결

1. **새 연결**에서 이름, 호스트, 포트, 사용자, 인증 방식을 입력한다. 개인키는 로컬 파일 경로를 입력한다.
2. 비밀번호와 Passphrase는 이번 연결에만 쓰거나 저장할 수 있다. 저장소를 쓸 수 없으면 '저장하지 않음'을 선택한다. 평문 파일로 대체 저장하지 않는다.
3. 처음 접속하는 서버는 서버 관리자가 제공한 SHA-256 지문과 대조한 뒤 신뢰한다. 변경되거나 폐기된 키는 연결을 차단하며, 앱에 우회 버튼이 없다.
4. 저장된 세션을 더블클릭하거나 Enter를 누른다. 수정, 즐겨찾기, 복제, 삭제는 세션을 우클릭한다. 세션 이름 옆에 `SSH`, `FTP`, `FTPS`가 표시된다. 탭마다 독립된 연결을 쓴다.

연결 종료는 탭을 우클릭해 고른다. 종료된 탭의 안내 카드나 탭 메뉴의 **재접속**은 새 셸을 열며 이전 명령을 다시 실행하지 않는다. tmux 세션을 지정한 연결은 같은 tmux 세션에 다시 붙는다([tmux 세션](#tmux-세션)).

### 인증 방식

- **지원 방식**: 비밀번호, 개인키(Ed25519, ECDSA, RSA), 암호화 개인키의 Passphrase, OS SSH agent, keyboard-interactive. 개인키·agent 인증 뒤 서버가 요구하는 OTP·MFA 질문도 표시한다. 응답은 저장하지 않으며 질문당 120초를 제공한다.
- **SSH agent**: Windows는 OpenSSH `ssh-agent` 서비스와 `ssh-add`로 등록한 키를 쓴다. macOS와 Unix는 `SSH_AUTH_SOCK`을 쓴다. 연결당 시도는 최대 5회이므로 agent에 키가 많으면 사용할 키를 정리한다.
- **RSA**: OpenSSH 일반·암호화, PEM PKCS#1, PKCS#8 일반·암호화 키를 읽는다. 2048~8192비트, SHA-256/512만 허용하고 SHA-1 `ssh-rsa` 서명은 허용하지 않는다. 오래된 PEM 암호화 형식은 OpenSSH나 PKCS#8로 변환해야 한다.
- **미지원**: Pageant, FIDO2 키 직접 접근, GSSAPI/Kerberos, agent forwarding, 호스트 CA 인증서.

### 점프 호스트

세션 폼 **고급 옵션**의 **점프 호스트**에서 경유할 SSH 프로필을 순서대로 추가한다. 경유 프로필 자체의 경로까지 포함해 최종 서버 외 최대 4홉이다. 홉마다 인증과 호스트키 신뢰를 따로 확인하고, 변경은 새 연결부터 적용된다.

### 시간 제한과 상한

| 항목               | 값                                                                               |
| ------------------ | -------------------------------------------------------------------------------- |
| 동시 SSH 연결      | 최대 32개                                                                        |
| KeepAlive          | 5~300초                                                                          |
| 접속·인증 타임아웃 | 5~120초                                                                          |
| 호스트키 확인 대기 | 별도 120초                                                                       |
| 출력 흐름 제어     | 연결당 32KiB 한 프레임만 미확인 상태로 전송. 렌더링 응답이 30초 없으면 연결 종료 |
| 분리 창 재생       | 최근 2MiB. 전체 세션의 영구 로그가 아니다                                        |

### 저장 위치

세션과 그룹은 앱 데이터 폴더의 `sessions.sqlite3`, 신뢰한 호스트키는 같은 폴더의 `known_hosts`에 저장한다. 사용자의 `~/.ssh/known_hosts`도 읽지만 수정하지 않는다.

## 인증정보 보관

세션의 사용자 이름과 접속 설정은 SQLite에, 비밀번호와 개인키 Passphrase는 OS 보안 저장소에 저장한다. SQLite에는 저장소 참조 ID만 남는다. 세션 폼의 **인증정보 보관 → 입력한 값을 암호화 보관**을 선택한다.

- 첫 접속 인증창에서 암호 저장을 선택하면 로그인 성공 후 보관하고 다음 접속에 사용한다. OTP는 저장하지 않는다.
- 세션을 복제해도 비밀정보는 복제되지 않는다. 세션을 삭제하면 해당 OS 항목도 삭제된다.
- 접속 대상을 바꾸면 기존 인증정보를 명시적으로 삭제하거나 교체해야 한다.
- 비밀번호는 세션 JSON 내보내기에 포함되지 않는다.

### 마스터 패스워드

**설정 → 마스터 패스워드 · 암호 보관함** 또는 세션 폼의 **고급 옵션**에서 12자 이상의 암호를 설정한다. 기존 저장 인증정보도 새 암호화 형식으로 이행한다. Argon2id(32MiB, 3회, 1 lane)로 유도한 키가 임의의 데이터 키를 감싸고, 각 인증정보는 AES-256-GCM과 독립 난수 nonce, 참조 ID 인증 데이터로 보호한다. OS 저장소에도 이 암호문만 기록하며 마스터 패스워드 자체는 저장하지 않는다.

- 앱을 시작하면 잠겨 있다. 해제 후 5분이 지나면 자동으로 잠기고, 즉시 수동으로 잠글 수도 있다. 이미 연결된 SSH·FTP 작업은 유지된다.
- 세션 수정 **고급 옵션**의 **저장된 암호 보기**는 매번 마스터 패스워드를 다시 확인한다. 30초 경과, 창 포커스 이탈, 닫기에 숨기며 클립보드에 자동 복사하지 않는다.
- 마스터 패스워드를 바꾸면 데이터 키와 저장 암호문을 모두 교체한다. 실패하면 기존 참조를 보존한다.
- **마스터 패스워드를 잊으면 복구할 수 없다.** 다른 기기로 옮길 수 있는 암호 백업·동기화는 제공하지 않는다.
- 마스터 패스워드를 설정하지 않아도 OS 보안 저장소의 암호화는 적용된다.

## 터미널

- **탭 메뉴**: 탭을 우클릭하거나 탭 표시줄의 ⋯를 누르면 터미널 검색, 세션 기록, 조작표, 오른쪽·아래로 분할(같은 대상에 새 연결, 오른쪽은 Ctrl+Shift+\\), 이 창 확대, 새 창으로 분리, 연결 종료·재접속, 탭 닫기가 나온다. 터미널 안의 우클릭은 메뉴 없이 바로 붙여넣는다.
- **상태바**: 아래 한 줄에 포커스된 칸의 대상, 상태, 인코딩, 기록 중 표시(`REC`), SSH 서버의 CPU·RAM을 보여 준다. 전체화면과 독립 창에서도 표시된다.
- **검색**: Ctrl+Shift+F나 탭 메뉴로 터미널 위에 검색창을 연다. Enter와 Shift+Enter로 다음·이전 결과로 이동하고, Esc로 표시를 지우고 입력으로 돌아간다.
- **복사와 붙여넣기**: 드래그 선택 자동 복사와 우클릭 붙여넣기가 기본으로 켜져 있고 **터미널 설정**에서 끌 수 있다. 끈 경우 Ctrl+Shift+C/V와 Shift+Insert를 쓴다. 여러 줄이나 제어 문자가 포함된 붙여넣기는 실행 전에 확인한다.
- **마우스를 쓰는 TUI**: vim, tmux 등에서는 Shift+드래그와 우클릭으로 터미널 선택·붙여넣기를 쓴다.
- **터미널 설정**: 설정 아이콘 → **터미널 설정**에서 모든 터미널에 공통인 값을 정한다. **표시**(글꼴 크기, 스크롤 기록), **마우스·키보드**(선택 복사, 우클릭 붙여넣기, Backspace 전송 방식, macOS의 Option 키를 Meta로 사용), **프로그램 연동**(조작표 자동 표시, 새 파일 패널의 경로 따라가기, 프로그램 상태 표시, 클립보드 복사 허용), **알림**(OS 알림, 터미널 벨)으로 나뉜다. 연결마다 다른 인코딩, tmux, 인증은 연결 편집에서, 세션 기록과 조작표 고정은 탭 메뉴에서 정한다.
- **키 입력**: SSH는 `TERM=xterm-256color`, `VERASE=DEL`, `IUTF8`을 요청한다. 서버가 이 설정을 덮어쓰면 **Backspace 전송 → Ctrl+H**를 선택한다. 잘못된 서버 terminfo, 로케일, 셸 설정까지 자동으로 고치지는 않는다.
- **독립 창**: 터미널을 새 창으로 분리해도 연결을 다시 만들지 않는다. 입력, 크기 변경은 한 창만 소유한다. 독립 창을 닫으면 해당 SSH 연결과 종속 작업이 종료된다. 검색, 세션 기록, 스니펫, 터미널 설정, 원격 파일은 독립 창 위쪽 **메뉴**에 있다.

### CLI 에이전트와 함께 쓰기

서버나 로컬에서 도는 CLI 에이전트의 작업 상태를 탭에 표시하고, 다른 일을 하는 동안 OS 알림으로 알려 준다. **터미널 설정**에서 각각 끌 수 있다. 서버에 별도 설정을 넣을 필요는 없으나, 프로그램이 상태 보고를 지원해야 한다.

- **줄바꿈**: Shift+Enter가 전송 없이 줄을 바꾼다. 프로그램이 지원하지 않으면 Enter로 동작한다.
- **링크**: Ctrl/Cmd+클릭으로 연다. 서버의 `localhost` 주소는 PC에서 바로 열리지 않으므로 [서버 포트 열기](#서버-포트-열기) 창이 뜬다.
- **탭 상태**: `완료`와 `오류`는 키를 입력하거나, 그 터미널로 포커스를 옮기거나, 그 탭을 열면 지워진다. `입력 대기`는 프로그램이 다음 상태를 알릴 때까지 남는다.
- **복사**: 프로그램이 요청한 복사는 사용자가 보고 있는 패널에서만 클립보드에 들어간다. **프로그램의 클립보드 복사 허용**으로 끌 수 있다.

**이미지와 파일 첨부**: 서버의 프로그램은 PC의 클립보드와 파일을 읽을 수 없다. 앱이 파일을 서버로 올리고 경로를 프롬프트에 입력한다. Enter는 누르지 않으므로 내용을 확인하고 직접 전송한다.

- **이미지**: 클립보드에 이미지가 있을 때 Ctrl/Cmd+Shift+V, Shift+Insert, 우클릭, **붙여넣기** 버튼 또는 macOS의 Cmd+V를 쓴다. 텍스트가 함께 있으면 텍스트를 붙여넣는다. Ctrl+V는 Vim 등이 쓰는 터미널 입력이라 가로채지 않는다. 프로그램이나 tmux(`mouse on`)가 마우스를 쓰는 중에는 우클릭이 그쪽으로 전달되므로 단축키나 Shift+우클릭을 쓴다. tmux에서는 경로가 활성 패널에 입력된다.
- **파일**: 터미널 패널 위로 끌어다 놓는다. 폴더와 심볼릭 링크는 보낼 수 없다.
- **확인**: PC의 데이터가 서버로 나가므로 보내기 전에 이름, 크기, 서버, 저장 위치를 보여 준다. 드롭은 매번 확인한다. 클립보드 이미지는 **이 연결에서는 다시 묻지 않음**을 고를 수 있고, 이 선택은 연결이 끝나면 사라진다.
- **저장 위치**: 서버의 `~/.cache/dachsterm/prompt/`에 본인만 읽을 수 있게 저장한다. 파일 이름의 영문, 숫자, `.`, `_`, `-` 외 문자는 `_`로 바뀐다. 7일이 지난 파일은 다음 전송 때 지운다. 이 폴더의 다른 파일은 건드리지 않는다.
- **상한**: 파일당 20MiB, 한 번에 10개다. 더 큰 파일은 파일 탐색기로 올린다.
- **로컬 탭**: 파일은 올리지 않고 경로만 입력한다. WSL에서는 드라이브 경로를 `/mnt/<드라이브>/…`로 바꾼다. 네트워크 경로(`\\서버\…`)는 거부한다. 클립보드 이미지는 프로그램의 이미지 붙여넣기 키를 쓴다.

### tmux 세션

연결이 끊겨도 서버의 작업을 유지하려면 세션 편집의 **고급 옵션 → tmux 세션 이름**을 입력한다. 영문, 숫자, `_`, `-`로 64바이트까지 쓸 수 있다. 서버에 tmux를 설치해 두어야 하며, 앱은 tmux나 서버 설정을 바꾸지 않는다.

- **재접속**: 같은 세션에 다시 붙어 실행 중이던 프로그램이 그대로 보인다. 명령을 입력해서 시작하지 않으므로 실행 중인 프로그램에 글자가 들어가지 않는다.
- **탭 닫기**: 서버의 tmux 세션은 계속 실행된다. 끝내려면 서버에서 tmux를 종료한다.
- **같은 이름**: 같은 이름을 쓰는 탭은 같은 화면을 공유하고 입력도 함께 들어간다.
- **서버에 tmux가 없을 때**: 일반 셸로 시작하고 안내를 표시한다.
- **스크롤 기록**: tmux가 관리하므로 앱의 스크롤 기록에는 남지 않는다.
- **경로 따라가기**: 셸에 입력하지 않으므로 자동으로 따라가지 않는다. 탭을 열 때 활성 패널의 폴더로 이동하고, 탐색기의 **경로 가져오기**로 다시 가져온다.
- **가져오기**: 세션 JSON에는 tmux 세션 이름이 포함되지 않는다.

CLI 에이전트를 쓸 때 권장하는 서버의 `~/.tmux.conf` 설정이다.

```text
set -g allow-passthrough on
set -g focus-events on
set -g mouse on
set -s extended-keys on
set -as terminal-features 'xterm*:extkeys'
```

**tmux 안의 작업 상태**: tmux 안의 CLI 에이전트는 상태를 직접 보낼 수 없어 훅 설정이 있어야 탭에 표시된다. **터미널 설정 → tmux 안에서 CLI 에이전트 상태 표시**에서 예시를 복사해 서버의 훅 설정에 넣는다. 다음 제한이 있다.

- 지금 보이는 tmux 창의 상태만 전달된다. 다른 tmux 창에 가려진 패널의 상태는 오지 않는다.
- 한 탭의 여러 tmux 패널은 구별되지 않고 하나의 상태로 표시된다.

### 터미널 인코딩

세션 폼의 **고급 옵션**에서 UTF-8(기본), CP949/EUC-KR, Shift_JIS, GBK, Big5, Windows-1252를 선택한다.

- 서버의 로케일과 실제 출력 인코딩에 맞춘다. 변경은 새 연결부터 적용된다.
- UTF-8 입력과 TUI를 쓰려면 서버 셸도 UTF-8 로케일이어야 한다.
- 수신 패킷 사이에 걸친 문자를 이어서 해석하고, 선택한 인코딩으로 표현할 수 없는 문자는 보내지 않는다.
- Unicode 정규화와 줄바꿈 변환은 하지 않는다.

매핑은 [WHATWG Encoding Standard](https://encoding.spec.whatwg.org/)와 [encoding_rs](https://docs.rs/encoding_rs/latest/encoding_rs/)를 따른다. CP949는 WHATWG EUC-KR의 Unified Hangul Code 매핑을 쓴다.

## 로컬 터미널

**＋ 새 연결** 메뉴나 사이드바의 셸 이름을 누르면 등록 없이 새 탭이 열린다.

- **Windows**: Windows PowerShell, 명령 프롬프트, 표준 경로의 PowerShell 7, 설치된 WSL 배포판을 자동으로 찾는다. 목록을 갱신해도 WSL 배포판을 시작하거나 설치하지 않는다. 새로 설치했다면 사이드바의 ↻로 다시 찾는다.
- **macOS**: `$SHELL` 또는 계정의 기본 셸을 로그인 셸로 연다.
- 시작 폴더는 사용자 홈이고, WSL은 배포판 홈이다.
- 최대 32개까지 열 수 있다. 탭이나 앱을 닫으면 셸을 정리하며, 재접속은 새 셸이다.
- 검색, 테마, 붙여넣기 확인, 분할, 동시 입력과 왼쪽 **파일**의 로컬 파일 트리를 쓸 수 있다. 모니터링, 터널, 새 창 분리는 제공하지 않는다.
- 로컬 파일 트리는 이 컴퓨터의 파일을 바로 다루므로 전송 큐를 쓰지 않는다. 새 파일·폴더, 이름 변경, 복사·이동·삭제, 외부 편집기로 열기를 제공한다. WSL 탭은 Linux 경로(`/home/...`)로 표시하고 복사·붙여넣기는 Windows 탭과 WSL 탭 사이에서도 된다.

## 스니펫·명령 모음·조작표

### 스니펫

**도구 → 스니펫**에서 이름, 설명, 본문, 그룹·태그를 저장하고 검색·복제한다.

- `{{경로}}` 같은 자리 표시자의 값은 실행할 때 입력하며 저장하지 않는다.
- 비밀번호, 개인키, Passphrase, OTP는 스니펫에 저장하지 않는다.
- 대상을 고르고 **입력만 넣기** 또는 **Enter 포함 실행**의 최종 본문을 확인한다. 선택한 대상에만 전달되며 동시 입력 그룹과 별개다. 여러 줄 본문은 별도로 확인하고, 재접속한 대상은 다시 확인한다.
- 원격 명령의 성공 여부는 터미널에서 직접 확인한다.
- 독립 SSH 창에서도 쓸 수 있다.

### 기본 명령·로그 필터

**도구 → 기본 명령·로그 필터**에서 기본 명령 26개와 필터 7개를 설명과 함께 복사한다. 교체할 부분을 강조하고 Enter 없이 복사한다. GNU/Linux 기준이다.

### 조작표

Bash·Zsh에서 vi, vim, less, tail을 실행하면 상태바 가운데에 핵심 키가 자동으로 나타나고, 끝나면 사라진다. **전체 보기**를 누르면 전체 표가 열린다. 경로 따라가기와 같은 방식으로 셸에 지금 세션에만 함수를 더해 프로그램의 시작과 끝을 알린다. 셸 설정 파일은 바꾸지 않고 입력한 키, 명령 인자, 이력은 수집하지 않는다. **터미널 설정 → vi·vim·less·tail 실행 중 조작표 자동 표시**로 끄며, 다시 켜면 새로 여는 셸부터 적용된다.

- Bash에서 별칭이나 함수로 바꿔 둔 이름(예: `vi`)은 그 이름만 건너뛰고 나머지는 그대로 표시한다.
- `sudo vim`, `command vim`, 파이프로 이어진 실행, tmux 안, 다른 셸, Windows 셸과 WSL에서는 자동으로 나타나지 않는다. 이때 전체 화면 프로그램이면 **전체 화면 프로그램 실행 중** 안내가 나온다. 탭 메뉴의 **조작표 전체 보기**에서 vi/vim, less, tail, cat 표를 직접 고르고 고정할 수 있다.
- cat은 바로 끝나므로 직접 고를 때만 표시한다.

## 세션 로그

탭 메뉴의 **세션 기록**으로 SSH, 로컬, WSL 출력을 UTF-8 파일로 기록한다. 기본은 꺼짐이다. 기록 중에는 탭과 상태바에 `REC`가 표시되고, 기록이 중단되면 상태바에 이유가 나온다.

- 시작·일시정지·재개·종료, 저장 폴더, 줄 타임스탬프, 크기·UTC 날짜 회전, 보관 파일 수, 이번 기록에만 적용되는 문자열 마스킹을 설정한다.
- 자동 기록은 해당 SSH 프로필이나 로컬 환경에 명시적으로 켠 경우에만 동작한다.
- 입력 이벤트와 인증 대화는 기록하지 않는다. **프로그램이 화면에 출력한 비밀은 자동으로 판별할 수 없다.**
- 미완성 줄은 최대 64KiB이고, 일시정지 경계의 조각은 버린다.
- 기록마다 새 폴더를 만들며 이전 폴더는 사용자가 관리한다.

## 분할과 동시 입력

- **배치**: 칸마다 탭 표시줄이 있다. **보기** 메뉴의 **모든 탭 좌우·상하·2 × 2·하나로**로 한 번에 정리하고, 분할선을 끌어 크기를 맞춘다. 분할선을 더블클릭하면 같은 크기로 돌아간다. 탭을 끌어 다른 탭 표시줄에 놓으면 그 위치로 옮기고, 터미널의 바깥쪽 가장자리에 놓으면 그 방향으로 나누고, 가운데에 놓으면 그 칸의 탭으로 합친다. 끄는 중에 Esc를 누르면 취소한다. SSH 탭은 앱 창 밖에 놓으면 새 창으로 분리된다. 패널 너비, 칸의 모양과 크기, 창 크기는 저장된다. 탭은 재시작 후 복원되지 않으므로 다시 시작하면 빈 칸이 있는 모양으로 열리고, 새 탭이 빈 칸을 앞에서부터 채운다.
- **입력 범위**: 터미널이 두 개 이상 보이면 상태바에 **개별 | 전체 | 선택**이 나타난다. **전체**는 보이는 터미널 모두에, **선택**은 각 칸 탭 표시줄의 **입력 받기**를 체크한 창에만 같은 입력을 보낸다. 두 개 이상 체크해야 전달된다. 동시 입력 중에는 대상 칸에 테두리가 생기고 상태바가 경고색으로 바뀌며, 대상이 아닌 칸에는 **입력 전달 대상 아님**이 표시된다. SSH, 로컬 셸, WSL을 함께 고를 수 있지만 셸마다 명령의 의미는 다를 수 있다. FTP와 PodTree 탭은 대상이 될 수 없다.
- **Ctrl+Shift+M**은 동시 입력 중이면 바로 중지하고, 아니면 **선택**만 연다. 실수로 눌러도 입력이 퍼지지 않도록 전체로 바로 들어가지 않는다.
- 보이는 창이 바뀌거나(탭 전환, 배치 변경, 이 창 확대 포함) 대상 연결이 끊기면 개별 입력으로 돌아가고 상태바에 이유가 잠시 표시된다. 새 연결과 재접속한 터미널은 자동으로 포함되지 않는다. 여러 줄을 붙여넣으면 확인창에 몇 개 창에 들어가는지 함께 표시한다. 독립 창은 터미널이 하나라 그룹을 만들 수 없다.
- **전체화면**: F11로 전환하고 다시 누르면 사이드바 배치를 복원한다. **이 창 확대**(탭 메뉴, Ctrl+Shift+Enter 또는 탭 표시줄 빈 곳 더블클릭)는 현재 칸만 확대했다가 되돌린다. 터미널은 유지되지만 다른 칸이 가려지므로 동시 입력은 해제된다. 동시 입력 상태와 중지 버튼은 전체화면에서도 상태바에 보인다.
- 창 너비가 700px 이하이면 포커스된 칸만 표시하고, 탭 표시줄의 **다음 칸** 버튼으로 다른 칸으로 옮겨 간다.

## 파일 탐색과 전송

### 탐색기

파일 트리가 패널의 중심이다. 폴더 왼쪽의 화살표는 그 자리에서 펼치고, 더블클릭은 그 폴더로 들어간다. 위쪽 아이콘은 폴더 이동·생성·전송·클립보드, 아래쪽 아이콘은 선택한 항목의 작업이며 마우스를 올리면 이름이 보인다. 전송 충돌 정책과 인코딩 정보는 아래쪽 **전송 및 편집**을 펼쳐서 본다. 이 영역은 진행 중인 전송이나 편집이 있으면 자동으로 열린다.

Ctrl/Cmd·Shift 다중 선택, Ctrl/Cmd+C/X/V/A, F2, Delete, F5, 컨텍스트 메뉴, 이름 검색과 정렬, 새 파일·폴더, 복사·이동·재귀 삭제, 권한 체크박스를 제공한다.

- 다른 SSH 연결 사이에서도 복사할 수 있다. FTP 복사는 같은 연결 안에서만 된다.
- 기존 대상은 덮어쓰지 않고 거부한다. 같은 폴더에 복사하면 `복사 1` 이름을 쓴다.
- 링크와 특수 파일의 복사는 거부하고, 삭제할 때 링크를 따라가지 않는다.
- SFTP 파일명은 UTF-8이다. 라이브러리가 손실 변환한 이름을 감지하면 경고하고 작업을 막는다. 비 UTF-8 파일명은 서버에서 먼저 UTF-8로 바꿔야 한다.
- 목록은 20,000개·20초가 상한이며, 하위 경로로 이동해 볼 수 있다.

### 터미널 경로 따라가기

기본으로 켜져 있고 탐색기의 **터미널 경로 따라가기**로 연결별로 끌 수 있다. 터미널 설정에서 새 연결의 기본값도 끌 수 있다. 경로 따라가기와 [조작표](#조작표) 자동 표시를 모두 끈 상태로 연결하면 셸에 아무것도 입력하지 않는다. OSC 7·1337 경로 알림을 받아 따라간다.

- **SSH**: 로그인 셸이 Bash·Zsh이고 첫 프롬프트가 뜨면 현재 세션에 경로 알림(조작표를 켜 두면 실행 알림 포함)을 자동으로 연결한다. 이 입력은 화면에 보이지 않고, Bash는 명령 기록에도 남기지 않는다. Zsh는 `HIST_IGNORE_SPACE`가 꺼져 있으면 기록에 한 줄 남는다. 세션 로그를 켠 경우 로그에는 이 입력이 기록된다. 서버 설정 파일은 바꾸지 않는다.
- **자동 연결을 하지 않는 경우**: 네트워크 장비·강제 명령·다른 셸(fish 등)처럼 Bash·Zsh로 확인되지 않는 서버에는 입력하지 않는다. 이때는 셸이 명령을 기다릴 때 **셸 경로 알림 연결**을 누른다. 이 버튼의 입력은 화면에 보인다. 세션에 tmux 이름을 지정한 연결은 셸에 입력하지 않는다([tmux 세션](#tmux-세션)). 직접 실행한 tmux 안의 셸은 tmux가 알림을 전달하지 않으면 따라갈 수 없다.
- **로컬**: PowerShell, 명령 프롬프트, WSL의 Bash는 시작할 때 경로 알림이 함께 설정된다. WSL의 Zsh는 **셸 경로 알림 연결**을 누른다. macOS 기본 셸(Bash·Zsh)은 SSH와 같이 자동으로 연결한다.

탐색기에서 폴더를 골라도 터미널에 `cd`를 실행하지는 않는다.

### 업로드와 다운로드

**파일 내용은 항상 바이너리 그대로 전송한다.** 텍스트 인코딩, BOM, CRLF/LF를 자동으로 바꾸지 않는다.

- 파일·폴더를 다중 선택하거나 파일 패널에 드롭한 뒤 확인해 업로드한다. 다운로드도 다중 선택할 수 있다.
- 빈 폴더와 하위 경로를 보존한다. 링크와 junction은 따라가지 않는다.
- 같은 이름의 파일은 기본으로 건너뛰며, 이름 변경이나 선택 전체 덮어쓰기를 고를 수 있다. 같은 폴더는 병합한다.
- 시간·달력 예약은 제공하지 않는다.

### 전송 큐

동시 2개 묶음, 64KiB 버퍼, 최대 100개다. 대기 순서 변경과 개별·선택 묶음의 일시정지, 취소, 재시도를 제공한다.

- 일시정지하거나 취소해도 부분 파일, 생성한 빈 폴더, 복구 계획을 보존한다.
- 앱을 다시 시작한 뒤 같은 프로필과 서버에 연결해 **이어서 보내기/받기**를 누른다. 원본 크기·수정 시각과 부분 파일 전체 바이트를 검증하고 재개하며, 기존 대상 파일에 이어 쓰지 않는다.
- 크기와 시각을 유지한 채 원본의 미전송 구간만 수정된 경우까지 잡아내지는 못한다. 전체 원본 해시가 아니기 때문이다.
- **부분 파일 삭제**는 명시적으로 선택해야 하며 원본은 지우지 않는다.

폴더 전송의 탐색·기록 상한과 재개 범위는 [폴더 전송·큐 기록](verification/phase-6-1.md)에 있다.

### 압축과 해제

SSH 서버에서 ZIP, TAR, TAR.GZ를 압축하고 푼다. 서버에 Python3와 Linux `renameat2`가 필요하고, ZIP 파일명 CP949·CP932·GBK·Big5 선택은 Python 3.11 이상이 필요하다. 절대·상위 경로, 링크·장치, 중복 항목, 20,000항목 또는 설정한 해제 크기 초과를 거부하며 새 대상에만 확정한다.

## 외부 편집

파일을 선택하고 **편집**을 누른다. 32MiB까지 지원한다.

- **편집기**: VS Code(`code`), Cursor(`cursor`), Sublime(`subl`) 또는 실행 파일 절대 경로와 JSON 인자 배열을 지정한다. 셸 문자열로 실행하지 않는다. Windows에서는 별칭으로 설치된 실제 EXE를 찾는다. macOS에서 CLI가 PATH에 없으면 앱 번들의 실행 파일 절대 경로를 지정한다.
- **저장 후 동작**: 기본은 저장 후 업로드 확인이고, 자동 업로드나 수동 업로드를 고를 수 있다. 저장은 2초 간격으로 감지하고 350ms 안정 구간을 기다린다. 확인이나 업로드를 취소해도 로컬 수정본은 보존한다. 편집기 자체의 자동 저장과 DachsTerm의 자동 업로드는 별개다.
- **파일 인코딩**: 기본 **원본 바이트 유지**는 편집기에서 인코딩을 고른다. 인코딩을 명시하면 로컬 UTF-8 작업 파일로 변환하고 저장할 때 원래 인코딩으로 되돌리며, 표현할 수 없는 문자가 있으면 업로드하지 않는다. 인코딩을 자동으로 추측하지 않는다.
- **충돌**: 원격 SHA-256이 편집 시작 시점과 다르면 덮어쓰기, 다시 받기, 다른 이름 저장 중에서 고른다. 다시 받기는 로컬 수정본을 `.bak`로 남긴다.
- **원자적 교체**: 서버가 `posix-rename@openssh.com`을 지원할 때만 기존 파일을 원자적으로 교체한다. 미지원 서버에서는 다른 이름으로 저장한다. 파일 모드는 유지하지만 ACL, xattr, 소유자 전체를 복제한다고 보장하지 않는다. 검사와 rename 사이에 다른 쓰기가 끼어드는 경쟁은 SFTP만으로 제거할 수 없다.
- **작업 파일**: 앱 데이터의 `edits/<UUID>/`에 사용자 전용 권한으로 저장한다. 실패, 충돌, 종료 시 복구본을 자동으로 지우지 않으며, 같은 세션과 대상에 다시 연결해 재시도한다. **동기화된 파일 정리**는 업로드가 끝난 파일만 지운다.

## FTP와 FTPS

세션 폼의 프로토콜에서 **FTP · 암호화 없음** 또는 **FTPS · 명시적 TLS**를 선택한다. 기본 포트는 21번이다. SSH와의 기능 차이는 [README의 지원 범위](../README.md#지원-범위)에 있다.

- **FTPS**: OS 신뢰 CA와 선택한 추가 PEM CA로 인증서와 서버 이름을 검증하며, 평문으로 전환하지 않는다.
- **FTP**: 네트워크의 인증정보와 내용을 암호화하지 않으며 화면에도 이를 표시한다.
- 두 방식 모두 Binary·PASV로 파일 바이트를 유지하고, 데이터 연결은 제어 연결의 서버로 제한한다.
- 파일명과 명령 인코딩은 UTF8, CP949, Shift_JIS, GBK, Big5, Windows-1252 중에서 고른다.
- 파일 작업은 중앙의 파일 탭에서 한다. 폴더 재귀 전송과 영속 전송 큐를 지원한다.
- 서버 간 복사, implicit FTPS, Active FTP, FXP는 제공하지 않는다.
- FTP RFC에는 원자적 no-replace rename이 없어, 확인과 rename 사이에 다른 클라이언트가 같은 이름을 만드는 경쟁을 완전히 막을 수 없다.
- 네트워크가 갑자기 끊긴 뒤 서버가 부분 파일을 잡고 있으면 정리될 때까지 기다렸다가 재개한다.

## 터널

**도구 → 터널**에서 Local, Remote 목적지를 지정하거나 SOCKS5 TCP CONNECT를 쓴다.

- 127.0.0.1 루프백에만 바인딩한다. SOCKS5 UDP/BIND와 공개 인터페이스 바인딩은 지원하지 않는다.
- 실행 터널은 최대 32개, 터널당 동시 스트림은 64개다.
- 자동 시작은 해당 SSH 세션이 연결되거나 재접속할 때 적용되며, 새 인증을 우회하지 않는다. 가져온 터널의 자동 시작은 꺼져 있다.

### 서버 포트 열기

서버에서 띄운 개발 서버를 PC 브라우저로 여는 임시 터널이다. **터널 → 서버 포트 보기**를 누르거나, SSH 탭에서 `localhost` 링크를 Ctrl/Cmd+클릭한다.

- 창을 열 때와 **새로고침**할 때만 서버의 포트 목록을 읽는다. Linux 서버에서만 동작하고, 1024 미만 포트는 기본으로 숨긴다.
- 사용자가 고른 뒤에만 터널을 연다. PC 포트는 서버와 같은 번호부터 시도하고, 사용 중이면 다음 번호를 최대 10개까지 시도한다.
- 저장되지 않으며 연결이 끝나면 함께 닫힌다. 같은 대상이 이미 열려 있으면 다시 쓴다. 실행 중인 터널은 이 창에서 중지한다.

## 서버 모니터링

Linux의 `/proc`과 `df -Pk`를 별도 SSH 채널로 수집한다. 서버에 아무것도 설치하지 않는다. 기본 5초 간격이고 2~60초로 바꾸거나 끌 수 있다.

- **CPU, NET**: 첫 샘플과 카운터 리셋 때는 측정 중으로 표시한다.
- **NET**: 기본은 loopback을 제외한 인터페이스 합계다. 브리지와 가상 인터페이스가 중복 집계될 수 있으며, 상세 보기에서 인터페이스 하나를 고를 수 있다.
- **RAM**: MemAvailable 기준이다.
- 상태바 오른쪽의 `CPU · RAM`을 누르면 상세 보기가 열린다.
- **DISK**: 상세 보기에 마운트별 사용량을 표시한다.
- 수집 출력은 256KiB·10초, 기록은 120개가 상한이다. 터미널과는 별도 채널, 별도 취소 범위로 동작한다.

## PodTree

**도구 → PodTree 열기**에서 연결된 SSH 또는 로컬 WSL·Bash를 고르고 의존성과 context를 확인한다. 내장 버전은 PodTree 2.4.0을 고정한 수정판이다.

- 실행 위치에 Bash 4 이상, kubectl, awk, sort 등이 있어야 한다.
- context와 namespace는 전용 탭에 고정되며, 기존 kubectl 설정이나 전역 current-context를 바꾸지 않는다.
- 스크립트는 사용자 전용 임시 폴더에 두고 정상 종료 시 정리한다. 기존 터미널 입력을 덮어쓰지 않는다.
- **조회 모드(기본)**: 쓰기, exec, debug, 캡처, 포트 포워딩, 네트워크 실행 프로브, raw proxy를 차단한다. proxy 기반 GPU·vLLM 수집도 꺼진다.
- **운영 모드**: 명시적으로 선택하며, 대상과 부작용을 확인한 뒤 동작을 실행한다.
- 클러스터 권한은 기존 RBAC를 따른다.
- 동시 입력, 스니펫, 세션 로그, 창 분리 대상에서 제외된다.
- 강제 종료나 네트워크 단절 시 원격 서버의 종료 처리에 따라 임시 파일이 남을 수 있다. 앱이 다른 프로세스나 임시 폴더를 일괄 삭제하지는 않는다.

## 세션 관리와 이관

- **설정 → 세션 일괄 수정 · 템플릿**에서 여러 세션을 한 번에 고치고 템플릿을 관리한다. 템플릿에 목적지, 사용자명, 비밀정보는 들어가지 않는다.
- **설정 → 세션 가져오기 · 내보내기**는 자체 JSON v3(v1, v2 읽기 지원), PuTTY `.reg`, 세션 북마크 파일(`.mxtsessions`, `.ini`), OpenSSH `config`를 미리 보고 선택해 추가한다. 제품별 기본 접속 정보만 변환한다.
- 내보내기에는 세션, 그룹, 터널, 템플릿만 포함한다. 비밀번호, Passphrase, 개인키 내용, OS 저장소 참조는 들어가지 않는다.
- 가져오기는 전체를 검증한 뒤 트랜잭션으로 추가하며 새 ID를 부여한다. 자동으로 접속하지 않는다.

지원표와 파일 규약은 [세션 가져오기·내보내기](session-transfer.md)에 있다.

## 복구와 진단

**설정 → 복구와 진단**에서 비밀정보 없는 설정 복구본을 만들거나 가져오고, 진단 JSON을 저장한다.

- 세션 수정·삭제, 그룹 삭제, 터널 변경, 설정 가져오기 전에 복구본을 자동으로 만들고 최근 10개를 보관한다.
- 복구본을 가져오면 기존 항목을 유지하고 새 ID로 추가한다. 저장 암호, 호스트키, 편집 파일은 포함되지 않으므로 PC 전체 백업을 대신하지 않는다.
- 앱은 같은 데이터 폴더를 동시에 수정할 수 없도록 인스턴스를 잠근다. DB가 손상되었거나 미래 버전이면 자동으로 초기화하지 않고 오류로 알린다.

## 로컬 게임

왼쪽 사이드바 아래의 **게임**을 펼쳐 고른다. 게임은 중앙 작업 영역의 일반 탭으로 열리고, 서버에서 프로그램을 실행하지 않는다.

- 탭을 전환하면 현재 판을 유지하고 실시간 게임을 일시정지한다. 돌아와서 **계속하기**(모험은 Space 또는 P)로 재개한다.
- **Esc / 작업으로 돌아가기**는 이전 작업 화면으로 돌아가고, 탭의 **×**는 현재 판을 끝낸다.
- 최고 기록은 로컬에 저장된다. 현재 판은 앱을 다시 시작하면 복원되지 않는다.

| 이동 | 방향키, A/D, 드래그 |

### 닥스의 모험

시드 기반 랜덤 횡스크롤 액션이다. 숲, 유적, 동굴, 설원이 순환하고 맵 선택에서 환경과 시드를 고를 수 있다.

| 조작            | 키          |
| --------------- | ----------- |
| 이동            | ←/→, A/D    |
| 점프            | ↑, W        |
| 물기, 시작      | Space, J, X |
| 빠른 밟기(공중) | ↓, S        |
| 일시정지        | P           |
| 효과음          | M           |

- **점수**: 간식 25, 물기 50, 밟기 75, 구간 통과 200. 체력 5, 쉼터 3곳.
- **보스전**: 구간 끝의 보스(체력 8)를 물기(1 피해)와 머리 밟기(2 피해)로 쓰러뜨리면 출구가 열린다. 처치하면 500점과 체력 2를 얻는다.
- **다음 구간**: 점수와 거리를 유지하고 체력 +1. **쉼터 재도전**: 점수와 획득을 유지하고 처치하지 못한 보스를 복원. **다시 시작**: 현재 맵을 처음부터 초기화.

### 닥스의 서바이버

자동 공격으로 버티는 생존 게임이다. 경험치를 모으면 전투가 멈추고 카드 3장 중 하나를 고른다. 일반 구간 60초를 버티고 3·6·9… 구간의 보스를 처치한 뒤, 성장과 HP를 유지해 다음 스테이지로 가거나 정산한다. 쉼터에서 골드로 영구 강화, 해금, 강화 환불을 할 수 있다.

| 조작           | 키                       |
| -------------- | ------------------------ |
| 이동           | WASD, 방향키, 8방향 패드 |
| 카드 선택      | 1/2/3, 방향키와 Enter    |
| 카드 다시 뽑기 | R                        |
| 일시정지·재개  | P                        |
| 음소거         | M                        |
| 작업으로 복귀  | Esc                      |

- 사망, 마무리, 포기, 탭 닫기는 보상을 정산한다. 저장에 실패하면 결과와 재시도 버튼을 유지한다.
- 다른 창에서는 읽기 전용이다. 저장을 지원하지 않는 환경의 임시 플레이는 보상을 저장하지 않는다.
- 앱을 다시 시작하면 전투 자체는 복원되지 않고, 마지막 체크포인트의 보상을 중단된 판으로 정산한다. 프로세스 강제 종료나 전원 차단에서는 저장이 유실될 수 있다.
