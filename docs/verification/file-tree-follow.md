# F.1 파일 트리와 경로 따라가기 검증

대상: `d8b5c5d` 위의 미커밋 변경. 같은 트리에서 다른 에이전트가 작업 중이었고, 게이트에는 당시 작업 트리의 그 변경도 함께 포함되었다.

## 동작

- SSH에 연결하면 사이드바가 **파일**로 전환된다. 700px 이하 창에서는 터미널을 가리지 않도록 서랍을 열지 않는다.
- 로컬 탭(PowerShell, 명령 프롬프트, WSL, macOS 기본 셸)에 파일 트리를 제공한다(`local_files.rs`, `LocalFilePanel.tsx`). SFTP가 아니라 로컬 파일 시스템을 직접 다룬다.
- 경로 따라가기가 켜져 있으면 알림을 자동으로 연결한다(`directoryHook.ts`).

| 대상                      | 방식                                                                             | 이유                                                     |
| ------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------- |
| SSH                       | 별도 exec 채널로 로그인 셸이 Bash·Zsh인지 확인하고 첫 프롬프트에 입력, 에코 숨김 | 네트워크 장비와 강제 명령 메뉴에 셸 문장을 보내지 않는다 |
| PowerShell, 명령 프롬프트 | 시작 인자                                                                        | ConPTY가 화면을 직접 그려서 입력 에코를 숨길 수 없다     |
| WSL Bash                  | `WSLENV`로 `PROMPT_COMMAND` 전달                                                 | 같은 이유                                                |
| WSL Zsh                   | 수동 버튼                                                                        | 시작 경로가 없다                                         |
| macOS Bash·Zsh            | SSH와 같은 입력 방식                                                             | 실제 PTY                                                 |

- 파일 패널은 트리 중심으로 재구성했다(`fileTree.tsx`, `files.css`). 폴더는 제자리에서 펼치고, 조작부는 아이콘 줄로 줄였으며, 전송 및 편집 영역은 패널의 35%까지만 쓰고 따로 스크롤한다.

## 알려진 제한

- 숨긴 입력도 백엔드 세션 로그에는 기록된다.
- 프롬프트가 여러 줄이면 첫 줄이 한 번 더 보일 수 있다.
- Zsh는 `HIST_IGNORE_SPACE`가 꺼져 있으면 기록에 한 줄 남는다.
- tmux 안의 셸은 tmux가 알림을 전달하지 않으면 따라가지 못한다.
- WSL의 `.bashrc`가 `PROMPT_COMMAND`를 덮어쓰면 수동 버튼이 필요하다.
- 로컬 트리에는 권한 변경과 압축이 없다.

실제로 확인한 내용:

- 실제 OpenSSH Bash: 자동 팔로우, 화면에 훅 미표시, 명령 기록 0건, 끄기·켜기·사이드바 전환 유지.
- 트레이가 열린 상태: 패널 전체 스크롤 없음, 트리 비율 25% 초과, 툴바 한 줄(`test-native.mjs` 단언).
- PowerShell, 명령 프롬프트, WSL Ubuntu: `cd` 따라가기, Linux 경로 목록, `$?` 유지.
- 로컬 트리: 새 폴더·새 파일·이름 변경·복사·덮어쓰기 거부·삭제, 트리 펼치기, 하위 항목 삭제.

## 수정한 결함

- 훅을 입력하는 순간 사용자가 먼저 친 명령의 출력이 함께 지워졌다. 네이티브 회귀에서 발견해 에코 시작 위치 앞의 출력을 보존하고, 입력 직후 1초는 훅을 보내지 않게 했다.
- `workspace_checks.rs`가 `resume()` 직후 `queued` 상태를 끝난 것으로 보고 실패했다. 대기 조건에 `queued`를 추가했다.
