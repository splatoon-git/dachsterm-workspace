# Phase 2~5 macOS 실기기 검증 절차

상태: 미실행. 현재 작업 환경에 Mac이 없다. 다음 절차는 계획이며 성공 결과가 아니다.

1. Mac에서 Node/Rust/Xcode CLI 준비 후 `npm ci`, `cargo build --workspace --locked`, `npm run tauri -- dev`. 기존 `phase-1-macos.md`의 Keychain/신뢰/인증/클립보드/한글 IME부터 검증.
2. 실제 SSH 연결 5개를 열고 단일/좌우/상하/2×2 및 패널 비율 변경. 각 `stty size`·한글·vim 확인. 탭 이동, 독립 창 분리 중 연속 출력의 누락/중복 및 종료 자원 확인. Retina 배율 변경/모니터 이동/창 크기 재실행 복원.
3. 실제 서버에서 UTF-8 한글/공백/NFC/NFD 파일명 목록과 이동, 숨김, chmod/rename/delete/mkdir. 비 UTF-8 파일명이 안전한 오류로 표시되는지 확인.
4. 바이너리/CP949/UTF-8 BOM/CRLF 파일 업로드·다운로드 SHA-256 일치. 네이티브 파일 선택/드롭, 전송 중 취소/네트워크 단절/종료, 원격 staging 정책 확인.
5. VS Code/Cursor/Sublime 또는 절대 실행 경로로 외부 편집. 원본 바이트 모드, CP949→UTF-8 작업본→CP949 저장, 표현 불가 문자 시 원격 보존. 로컬 `edits` 권한0700, 충돌/다시 받기 백업/다른 이름/재실행 복구/정리.
6. Local/Remote/SOCKS5 실제 왕복, TCP CONNECT 도메인·IPv4/IPv6, 포트 충돌·서버 거부·루프백, SSH 재접속 시 선택한 터널만 재시작, 종료 후 모든 포트/소켓 정리.
7. Linux CPU/RAM/NET/DISK/Load와 실제 도구 값 비교, 2/5/60초 주기, 켜기/끄기, 인터페이스 선택, 첫 샘플/오래된 값, 수집 실패 중 터미널 지속.
8. `npm run tauri -- build --bundles app,dmg`; 설치→실행→전체 작업→종료→재실행. 개인 빌드와 공개 배포용 Developer ID 서명/공증을 구분. 공개 배포 자격증명은 코드·로그에 남기지 않는다.
9. 장시간 연결/대량 출력/대용량 파일/반복 연결, 절전·복귀와 네트워크 변경 확인. OS 버전/아키텍처/명령/관찰/실패/산출물 SHA-256을 이 문서에 기록하고 progress의 5.2/5.3 상태를 갱신.

10. 마스터 보관함 설정·기존 Keychain 비밀 이행·재인증 보기/창 blur·30초 숨김·5분 잠금·변경·재시작, DB rollback. 인증정보/암호를 스크린샷·로그에 포함하지 않는다.
11. FTP/FTPS OS 신뢰 CA·사용자 CA·잘못된 인증서 거부, UTF8/CP949 파일명, Binary 보존, FTP/SFTP 중지/재시작 재개/원본 변경·부분 내용 불일치 거부. 전송 중 종료 후 같은 프로필/대상으로만 복구.
12. 다중 선택·클립보드·재귀 복사/이동/삭제·권한·압축/해제, 선택 영역 높이·더블클릭, 멀티 입력의 대상 종료/재접속 해제, 12개 테마의 연결 중 전환·독립 창 동기화.
